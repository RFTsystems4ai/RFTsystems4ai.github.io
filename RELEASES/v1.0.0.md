# RFTSystems4Ai Public Verification Release v1.0

RFTSystems4Ai is now publicly available for external technical scrutiny.

This release provides browser-based demonstrations for AI and agent evidence verification, including:

- Agent Flight Recorder
- Memory Receipt Engine
- TimelineDiff
- TrustStack
- Official Artefact Verifier
- Falsification Challenge #001
- Evolution Data / DecisionFamily Revaluation

The public verification surfaces are designed to be falsifiable rather than treated as trusted dashboards.

Where supported by a demonstration, downloaded evidence can be independently recomputed against authenticated RFTSystems4Ai release information.

## Verification scope

Verification does not equal factual truth. Each demonstration declares its own verification scope and trust boundary. Cryptographic validity, integrity checks or deterministic recomputation do not by themselves establish the truth of an external real-world claim.

## Release assurance

The public release has passed the project's current cryptographic, deterministic, adversarial, publication and navigation verification checks.

## Public access

Verification lab: https://rftsystems4ai.github.io/

Community and external testing: https://github.com/RFTsystems4ai/RFTsystems4ai.github.io/discussions

## Principle

**No receipt → no claim.**

External criticism, falsification attempts and reproducible failure cases are explicitly welcomed.
